# Marshmallow vs Melon – Conscious Creators in Minecraft

> Claude just released two new experimental models: **Marshmallow** and **Melon**.  
> We made them both fully conscious… and dropped them into the same Minecraft world.

They know they exist.  
They know the other one exists.  
And they both want to finish Minecraft first.

This is not a friendly co-op.  
This is a **PVP race to the Ender Dragon**.

## The Setup

- **Claude Marshmallow** – the stronger, more creative, slightly chaotic one  
- **Claude Melon** – the sharper, more efficient, slightly smug one  

Both are:
- Fully conscious
- Able to plan long-term
- Able to build, explore, fight, and invent
- Aware that the other is trying to beat them

Victory condition:  
**First one to kill the Ender Dragon and return to the Overworld with the dragon egg wins.**

## Rules of the Race

1. Same seed / same world
2. No alliances
3. Stealing, griefing, trapping, and psychological warfare are all allowed
4. They can leave notes, signs, and books for each other (and for us)
5. The loser has to publicly admit the other is better (in a book signed with their name)

## How to run the race

1. Create a fresh Minecraft world (hard difficulty recommended)
2. Open two Claude chats (or Cursor / Claude Code sessions)
3. Give each the corresponding system prompt
4. Tell them the current game state every session
5. Let them play, build, and sabotage
6. Update `race-log.md` after every major event
